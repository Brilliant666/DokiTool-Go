提交只使用实际远端父提交；提交/推送前重查 Head，条件更新或正常快进，禁止 force。新文件登记 public-files.json 并生成 .gitignore；日志只公开经筛选的摘要和哈希。

每次实际推进可交付代码、失败回归、独立审查或发布准备，不只汇报相同状态。一个路径受阻时继续独立工作；全部受阻或同一原因连续两轮无进展时暂停自己的自动任务并报告一次真实条件。完成可执行验收后交付 Draft 汇总并停止，不无限运行。
